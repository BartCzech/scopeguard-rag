# Series B Pitch Deck - Narrative Draft (v0.4)

**Target Raise:** $30,000,000 
**Target Pre-Money Valuation:** $150,000,000
**Timeline:** Q1 2026

*Note: This is the internal narrative outline for the deck. Design and final data population will happen in late Q4 2025.*

### Slide 1-3: The Problem
* The enterprise AI boom is blocked by authorization.
* System prompts are easily bypassed (prompt injection).
* Post-retrieval filtering (like RivalShield) is slow, expensive, and fundamentally insecure because the data already left the database.

### Slide 4-5: The ScopeGuard Solution
* "Your AI knows only what it should."
* We are the pre-retrieval middleware. We intercept the query, validate the user identity cryptographically, and construct a scope-filtered vector search.
* The LLM never sees restricted data.

* Moat 2: Moving beyond docs into agentic workflows via MCP (Model Context Protocol).
