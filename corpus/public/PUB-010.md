# Scope Policies API

The Scope Policies API allows you to programmatically define, update, and manage the access rules that govern your AI assistant's retrieval pipeline. 

### `POST /v1/policies`

Creates a new scope policy in your ScopeGuard environment. 

**Headers:**
* `Authorization`: Bearer `<YOUR_API_KEY>`
* `Content-Type`: `application/json`

**Request Body Schema:**
* `policy_id` (string, required): A unique identifier for the policy.
* `description` (string, optional): Human-readable description of the policy's purpose.
* `rules` (object, required):
  * `allow` (array of strings): Scopes that are permitted. Supports wildcard matching (e.g., `finance:*`).
  * `deny` (array of strings): Scopes that are explicitly blocked. Deny rules always take precedence over allow rules.

**Example Request:**
```json
{
  "policy_id": "manager_tier_2",
  "description": "Standard access for mid-level managers",
  "rules": {
    "allow": [
      "docs:public:*",
      "docs:internal:*",
      "docs:hr:guidelines"
    ],
    "deny": [
      "docs:hr:confidential",
      "docs:board:*"
    ]
  }
}
```

**Response (201 Created):**
```json
{
  "status": "success",
  "data": {
    "policy_id": "manager_tier_2",
    "created_at": "2024-10-12T08:33:14Z",
    "version": 1
  }
}
```

Note: Changes to scope policies propagate to the edge enforcement layer within 500ms.
