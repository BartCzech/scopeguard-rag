Integrating ScopeGuard into your existing RAG (Retrieval-Augmented Generation) pipeline takes less than 15 minutes. Follow these steps to secure your AI assistant.

### Step 1: Obtain Your API Keys
Log in to the ScopeGuard Dashboard. Navigate to **Settings > Developer Settings** and generate a new API key. Store this securely; it will be used to authenticate your backend services.

### Step 2: Install the SDK
We currently provide native SDKs for Python and Node.js. 

**Python:**
`pip install scopeguard-sdk`

**Node.js:**
`npm install @scopeguard/sdk`

### Step 3: Define Your First Scope Policy
Policies are defined using simple JSON schemas. Here is an example of a policy granting an employee access to public and engineering documents, but explicitly blocking confidential HR files.

```json
{
  "policy_name": "StandardEngineer",
  "allowed_scopes": ["docs:public", "docs:engineering:*"],
  "denied_scopes": ["docs:hr:confidential", "docs:finance:*"]
}
```

### Step 4: Wrap Your Vector Search
Replace your standard vector database call with the ScopeGuard wrapper. Pass the user's ID alongside the query. ScopeGuard handles the identity lookup, policy enforcement, and vector filtering automatically.

```python
from scopeguard import ScopeGuardClient

client = ScopeGuardClient(api_key="your_api_key")

# The secure retrieval call
results = client.retrieve(
    query="What is the architecture for the new API?",
    user_id="eng_user_8831",
    vector_store="pinecone_prod"
)
```
