**ScopeGuard v2.4 (Latest)**
* **Feature:** Slack Integration. Enterprise and Business tier customers can now receive real-time alerts in Slack when a user repeatedly attempts to query out-of-scope data.
* **Enhancement:** Reduced embedding processing latency by 12% for Pinecone integrations.
* **Fix:** Resolved a timeout issue occurring during large batch policy updates via the API.

**ScopeGuard v2.3**
* **Feature:** Added native integration support for Chroma vector databases. 
* **Enhancement:** Enhanced error messaging in the SDK when identity tokens are expired or malformed.
* **Security:** Rotated internal API signing keys (routine maintenance).

**ScopeGuard v2.2**
* **Feature:** Audit Log Dashboard. The ScopeGuard web console now includes a fully searchable interface for auditing intercepted queries, blocked retrieval attempts, and API key usage.
* **Feature:** CSV Export for audit logs to support compliance reporting.

**ScopeGuard v2.1**
* **Enhancement:** Upgraded the Node.js SDK with full TypeScript support and improved type definitions for policy configuration.
* **Fix:** Corrected a UI bug in the Developer Settings page where newly generated API keys were sometimes truncated.

**ScopeGuard v2.0 (Major Release)**
* **Feature:** Granular Scope Inheritance. Administrators can now define nested policies and hierarchical permissions (e.g., granting `docs:engineering:backend` automatically grants access to `docs:engineering:backend:api`). 
* **Breaking Change:** The `/v1/auth/verify` endpoint has been deprecated in favor of the new combined `/v2/retrieve` workflow. Update your SDKs accordingly.
