# Leadership Sync: 2025 H1 Roadmap

**Date:** 2024-11-20
**Attendees:** Bart Check, Paul Kepovitz, Sarah (Product), Marcus (Eng Lead)

### High-Level Goals for H1
Following the Series A close, the board is pushing us to accelerate enterprise adoption. Our roadmap needs to reflect features that unblock compliance-heavy deployments. 

### Q1 2025 Initiatives
* **Real-Time Scope Revocation:** Right now, we rely on JWT expiration (usually 1 hour) or manual cache clearing. Enterprise CISOs want an API endpoint to instantly kill a user's retrieval access if their account is compromised.
    * *Status:* Paul is reviewing the architectural impact on Redis.
* **Multi-Tenant Embedding Isolation (Enterprise Tier):** As discussed in the INC-2024-08-12 post-mortem, logical separation isn't cutting it for high-value clients. We need automated provisioning of dedicated Pinecone indices per tenant. 
    * *Status:* Marcus is drafting the ADR.

### Q2 2025 Initiatives
* **Model Context Protocol (MCP) Native Support:** This is the big bet. As agents get more autonomous, standard RAG isn't enough. We need to be the authorization layer for tools, not just docs.
    * *Status:* Bart is pushing for an early alpha by May. We want to be first to market with an enterprise-grade MCP auth middleware. 
* **EU Data Center (Frankfurt):** Necessary for GDPR-heavy prospects. 
    * *Status:* DevOps will begin AWS terraform replication in April. 

**Parking Lot:**
* DLP (Data Loss Prevention) for outbound prompts. (Pushed to H2, let RivalShield own this space for now while we focus on retrieval).
