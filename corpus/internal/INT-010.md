# Q3 2024 Cloud Infrastructure Spend

**Prepared By:** DevOps & Finance
**Date:** October 5, 2024

### Overview
Total AWS and related infrastructure spend for Q3 2024 averaged **$47,000 per month**. With the Series A funds secured, we have a healthy ~29 month runway, but board members (specifically Crest) have flagged our gross margins. We need to optimize our vector database and compute costs before scaling the Enterprise tier.

### Spend Breakdown (Monthly Average)

| Service Category | Monthly Cost | Trend vs Q2 |
|------------------|--------------|-------------|
| Pinecone (Managed Vector DB) | $18,400 | 🔺 +22% |
| AWS EC2 (GPU Instances) | $14,200 | 🔺 +15% |
| AWS RDS (PostgreSQL) | $4,500 | ➖ Flat |
| AWS ElastiCache (Redis) | $3,800 | 🔺 +5% |
| AWS Data Transfer / NAT | $3,100 | 🔺 +10% |
| Misc (S3, CloudWatch, LB) | $3,000 | ➖ Flat |
| **TOTAL** | **$47,000** | |

### Key Drivers & Action Items
1.  **Pinecone Costs:** As our user base grows, the read operations on Pinecone are scaling linearly. 
    * *Action:* We must aggressively optimize our Redis caching layer for scope pre-flight checks so we don't hit Pinecone for identical, consecutive queries. 
2.  **GPU Instances:** We are running too many orphaned `g4dn.xlarge` instances for our internal embedding pipeline. 
    * *Action:* Implement aggressive auto-scaling and auto-kill scripts for zombie embedding workers (assigned to DevOps in the last retro).
3.  **Data Transfer:** Cross-AZ traffic is unnecessarily high between our API gateway and Redis clusters.
